# Контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

## Основа проекта

Проект `kr4-js-shop` создан на основе проекта `kr3-responsive-shop`.

В качестве основы используется адаптивная версия HTML/CSS-интернет-магазина из контрольной работы №3.

Выполнено:

- создан отдельный репозиторий `kr4-js-shop`;
- перенесена основа интернет-магазина из КР №3;
- создана папка `js`;
- создан файл `js/data.js`;
- создан файл `js/main.js`;

- написаны функции форматирования цены, расчёта скидки и определения статуса товара;
- результат выведен в консоль;
- результат выведен на страницу через `textContent`.

Функции:

- `formatPrice(price)` — форматирует цену с разделителями разрядов;
- `calculateDiscount(price, discountPercent)` — считает размер скидки;
- `calculateFinalPrice(price, discountPercent)` — считает цену со скидкой;
- `getProductStatus(product)` — возвращает статус наличия;
- `createProductSummary(product)` — собирает краткое описание товара.

## Принцип безопасного вывода данных

Для вывода пользовательских данных и данных, которые в будущем могут прийти из формы, `localStorage` или API, используется `textContent`, а не `innerHTML`.

`innerHTML` разбирает строку как HTML-разметку. Если записать в него строку `<img src=x onerror=alert(1)>`, браузер создаст изображение и выполнит код из атрибута `onerror`. Это XSS-уязвимость.

`textContent` записывает строку как обычный текст: та же строка будет показана на странице как набор символов и не выполнится.
