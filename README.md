## Массив товаров

Каждый товар в `js/data.js` имеет одинаковую структуру:

```js
{
  id: 1,
  title: 'Смартфон Galaxy X',
  category: 'smartphones',
  price: 54990,
  discountPercent: 10,
  rating: 4.7,
  isAvailable: true,
  image: 'images/galaxy-x-640.jpg',
  description: '6.5" AMOLED, 128 ГБ, 8 ГБ ОЗУ, тройная камера.'
}
```

Категории: `smartphones`, `laptops`, `headphones`, `accessories`. Они совпадают со значениями в фильтре каталога.

## Реализованная логика

- **Поиск** — `searchProducts` приводит запрос и название к нижнему регистру, убирает пробелы через `trim()` и проверяет вхождение через `includes()`.
- **Фильтрация** — `filterProductsByCategory` оставляет товары выбранной категории; `filterFavoriteProducts` оставляет избранные.
- **Сортировка** — `sortProducts` сортирует копию массива по цене или по названию через `localeCompare`.
- **Рендер** — `getPreparedProducts` применяет поиск, фильтры и сортировку к состоянию `catalogState`, `renderProducts` создаёт карточки через `createElement`, `updateCatalog` перерисовывает каталог при каждом изменении.
- **События** — `input`, `change`, `click`, `submit` через `addEventListener()`; кнопки карточек обрабатываются делегированием событий на контейнере.
- **Валидация формы** — имя, e-mail, телефон, тема и согласие проверяются при отправке и при вводе; ошибки выводятся рядом с полями через `textContent` и связываются с полями через `aria-describedby` и `aria-invalid`.

## Безопасный вывод данных

Для вывода пользовательских данных и данных, которые могут прийти из формы, `localStorage` или API, используется `textContent`, а не `innerHTML`.

`innerHTML` разбирает строку как HTML-разметку. Если записать в него строку `<img src=x onerror=alert(1)>`, браузер создаст изображение и выполнит код из атрибута `onerror`. Это XSS-уязвимость.

`textContent` записывает строку как обычный текст: та же строка будет показана на странице как набор символов и не выполнится. В проекте `innerHTML` не используется.

## Как проверить

1. Открыть `catalog.html`, ввести «ноут» в поиск, выбрать категорию и сортировку.
2. Ввести «zzz» и проверить пустое состояние.
3. Отметить пару товаров сердечком и включить «Только избранное».
4. Переключить страницы каталога.
5. Добавить товары в корзину и проверить счётчик в меню.
6. Открыть `cart.html`, изменить количество, применить промокод `STUDENT10`, перезагрузить страницу.
7. Нажать «Оформить заказ», проверить подставленные товары, отправить пустую форму, затем заполнить её корректно.
8. Нажать «Подробнее» в карточке и проверить страницу товара.
9. Включить тёмную тему и перейти на другую страницу.
10. Открыть DevTools → Console и убедиться, что ошибок нет.
